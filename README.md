## Project
A responsive Marwin-themed shop concept for books, games, toys, and gifts. This is a front-end learning demo; the bag, ratings, favorites, and signup forms do not connect to a real backend or payment service.

## Files
- `index.html` — page structure and content
- `style.css` — responsive design, themes, transitions, and animations
- `script.js` — product data, filtering, search, ratings, bag counter, forms, keyboard navigation, sound, and modal

## Run locally
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code or another editor.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. No package installation or build step is required.

## Main interactions to test
- Filter by Books, Games, Toys & Play, or Gifts.
- Search for a product such as `book`, `gift`, or `puzzle`.
- Add an item to the bag, favourite a product, and click a star to rate it.
- Switch day/night theme and use Surprise me to trigger a short sound and animation.
- Expand the story, submit/clear the signup form, open the newsletter modal, and open FAQ questions.
- Focus a navigation link and use Left/Right arrow keys to move between menu links.
